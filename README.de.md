## 📖 Übersicht

**RustServerPanel** ist ein modernes und hochleistungsfähiges Open-Source-Verwaltungspanel, das speziell für **Rust** entwickelt wurde. Es verbindet sich nahtlos über **WebRCON** für eine blitzschnelle Steuerung in Echtzeit.

## ✨ Hauptfunktionen

- 🚀 **Echtzeit WebRCON Konsole**: Latenzfreie Befehle mit Syntaxhervorhebung.
- 👥 **Spielerverwaltung**: Live-Tracking, One-Click Kicks/Banns.
- 🧩 **Plugin Manager**: Direkte uMod/Oxide Integration zur Installation von Plugins.
- ⚙️ **Konfigurationseditor**: Sichere Bearbeitung von Server-Convars (JSON).
- 💾 **Automatische Wipes & Backups**: Plane Map-Wipes, BP-Wipes und Backups via Cron.
- 🌐 **Mehrsprachig**: Native Unterstützung für 6 Sprachen.

## 📦 Installation
```bash
git clone https://github.com/k0d1r/rustserverpanel.git
cd rustserverpanel/backend
npm install && npm run build && npm start
```
*Standard-Login: `admin`, Passwort: `admin123`*
