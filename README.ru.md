## 📖 Обзор

**RustServerPanel** — это современная, высокопроизводительная панель управления игровым сервером с открытым исходным кодом, созданная специально для **Rust**. Обеспечивает бесперебойную связь через **WebRCON** для молниеносного контроля в реальном времени.

## ✨ Ключевые особенности

- 🚀 **Консоль WebRCON**: Встроенный терминал без задержек с подсветкой синтаксиса.
- 👥 **Управление игроками**: Отслеживание в реальном времени, кик/бан в один клик.
- 🧩 **Менеджер плагинов**: Прямая интеграция с uMod/Oxide для установки плагинов.
- ⚙️ **Редактор конфигураций**: Безопасное редактирование конваров и JSON.
- 💾 **Автоматические вайпы (Wipes)**: Расписание вайпов карты, чертежей и бэкапов через Cron.
- 🌐 **Мультиязычность**: Поддержка 6 языков.

## 📦 Установка
```bash
git clone https://github.com/k0d1r/rustserverpanel.git
cd rustserverpanel/backend
npm install && npm run build && npm start
```
*Логин по умолчанию: `admin`, Пароль: `admin123`*
