## 📖 概述

**RustServerPanel** 是专门为 **Rust** 构建的现代、高性能且完全开源的游戏服务器管理面板。旨在取代臃肿的商业面板，它通过 **WebRCON** 无缝连接，提供对服务器、插件和玩家的极速、实时控制。

采用令人惊叹的玻璃拟物化 UI（锌深色主题）构建，无论您是运行单个原版服务器还是大型模组网络，它都能提供无与伦比的管理体验。

## ✨ 主要功能

- 🚀 **实时 WebRCON 控制台**: 体验零延迟命令，集成了语法高亮、自动滚动和聊天过滤的终端。
- 👥 **高级玩家管理**: 实时玩家跟踪、一键踢出/封禁、Steam 个人资料链接。
- 🧩 **一键式插件管理器**: 与 uMod/Oxide 直接集成。直接从 Web 面板浏览、安装、更新和删除插件。
- ⚙️ **变量和配置编辑器**: 使用内置的 Monaco 语法验证安全地编辑服务器 convar 和 JSON 配置文件。
- 💾 **自动任务和清档**: 使用强大的 Cron 表达式安排自动清档（地图、蓝图、完全）和 ZIP 备份。
- 🌐 **全球 i18n 支持**: 完美支持 6 种语言（英语、土耳其语、中文、西班牙语、俄语、德语）。

## 📦 安装指南
```bash
git clone https://github.com/k0d1r/rustserverpanel.git
cd rustserverpanel/backend
npm install && npm run build && npm start
```
*默认登录用户名：`admin`，密码：`admin123`*
